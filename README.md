## 📌 Projetos em destaque

**Backend & Dados**
- 🔗 [**backend-django**](https://github.com/riessz/backend-django) — Sistema de Monitoria IBMEC: API REST em Django com autenticação por perfil (aluno/professor) e CRUD de vagas.
- 🔗 [**django-gastos**](https://github.com/riessz/django-gastos) — App fullstack de controle financeiro pessoal (Django REST + React), com autenticação de usuários e visualização por período.
- 🔗 [**isp-analise**](https://github.com/riessz/isp-analise) — Pipeline ETL de dados de criminalidade do RJ (Pandas), análise de série temporal, 27 testes automatizados (pytest) e dashboard interativo (Streamlit).

**Sistemas Embarcados & IoT**
- 🔗 [**se-projeto**](https://github.com/riessz/se-projeto) — Sistema de chamados de suporte para sala de aula: ESP32 com sensores → MQTT (Mosquitto) → bot Python com escalonamento automático (Telegram) → dashboard em tempo real (Flask/WebSocket).
- 🔗 [**se-projeto-quinta**](https://github.com/riessz/se-projeto-quinta) — *Mesh-Alarm*: digital twin de uma rede mesh de sensores (ESP32 + LoRa) para detecção de incêndio florestal, com algoritmo guloso de cobertura, propagação de alerta por BFS e simulação de espalhamento do fogo por autômato celular sobre mapa real.

**Linux & Automação**
- 🔗 [**linux-bash-monitoring**](https://github.com/riessz/linux-bash-monitoring) — Script interativo em Bash puro para monitoramento de CPU, memória, disco e processos, usando apenas comandos nativos do Linux (`top`, `free`, `df`, `ps`, `/proc`).

**Fundamentos**
- 🔗 [**java-game-oop**](https://github.com/riessz/java-game-oop) — Jogo em Java aplicando conceitos de Programação Orientada a Objetos, em dupla.
